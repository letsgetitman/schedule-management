## 0. 작성 규칙 (데이터 스키마)

| 필드 | 설명 |
|---|---|
| `ID` | `KR-YYYYMMDD-NN` (당일 중요도 순번) |
| 일자 헤더 | KOSPI 종가(전일 대비). `≈`는 인접일 종가·등락률로 역산한 근사치, "미확인"은 종가를 확보하지 못한 날 |
| `클린데이` | **Y** = 지배적 사건 1개가 당일 움직임 대부분을 설명(가중치 학습용 후보) / **N** = 복수 사건 혼재(공동 원인으로만 사용) |
| `분류` | 반도체/AI · 통화정책 · 거시지표 · 정책(국내) · 정책(해외) · 정치 · 지정학 · 해외증시 · 기업실적 · 기업이벤트 · 수급 · 시장제도 · 환율 · 테마 |
| `발표시각(KST)` | 사건이 공개된 시각. 장전(~09:00)/장중(09:00~15:30)/장후·새벽(해외) 구분의 근거 |
| `예정/돌발` | **예정** = 일정이 사전 공지된 이벤트(금통위·CPI·실적 등, 식별력 높음) / **돌발** = 사전 예고 없는 사건 |
| `예상 vs 실제` | 컨센서스·시장 예상 대비 결과(서프라이즈 변수). 예상된 사건은 이미 가격에 반영됐을 수 있음 |
| `N` 뉴스량 | 1~5. 보도 매체 수·속보 여부 기준의 **정성 추정치**(사후 해설 기사 제외 지향) |
| `I` 영향력 | 1~5. 5 = 지수 ±5% 이상 또는 사이드카 직접 원인 / 4 = ±2~5% / 3 = ±1~2% / 2 = 섹터 한정 / 1 = 개별 종목·테마 |
| `방향` | ▲ 상승 요인 / ▼ 하락 요인 / ◆ 혼조·중립 |
| `중요도` | **N × 0.4 + I × 0.6** (5점 만점). 당일 내 이 점수 순으로 정렬 |
| `신뢰도` | **A** = 장중 발표 직후 즉각 반응이 기사로 확인 / **B** = 장외(해외·장전·장후) 발표 후 첫 거래일 반응 / **C** = 수급·심리 등 언론 해석 위주 / **D** = 검색 미검증(모델 사전지식 기반) |
| `노출 대상` | 종목군·국가 간 비교(이중차분)에 쓸 영향 대상 |

### 사용상 주의
1. **원인 서술은 가설입니다.** 마감시황 기사의 "○○ 때문에"는 사후 해석이 많으므로, 실제 가중치는 일봉 데이터와 붙여 **초과수익률**(글로벌·섹터 요인 제거)로 검증하세요.
2. **신뢰도 D 구간(2025-08-21 ~ 12-30)은 미검증입니다.** 이번 세션의 웹 검색 한도(200회)가 8/20 수집 시점에 소진되어, 이후는 모델 사전지식과 앞서 확보한 검색 스니펫 일부(9/26·10/16·10/29·11/5·12/22~12/30)로 작성했습니다. 일자·수치를 반드시 재확인하세요. 해당 구간은 굵직한 이벤트만 수록했고, 이벤트가 불확실한 날은 비웠습니다.
3. 1~8월 구간의 종가·수급은 국내 언론 마감시황 기사(이투데이·아주경제·이데일리·인포스탁데일리 등) 검색으로 교차 확인했고, 일부 `예상 vs 실제` 수치(컨센서스 등)와 발표 시각은 모델 지식으로 보완했습니다.
4. `N` 뉴스량은 추정치입니다. 정밀 가중치가 필요하면 빅카인즈(BIG KINDS) 등에서 키워드별·시점별 기사 수로 교체하세요.
5. 동봉한 `KR_market_events_2025.csv`는 같은 내용을 1행=1사건으로 펼친 파일입니다(DB 적재용).

## 2. 사건 유형별 관찰 (가중치 설계 참고)

- **해외 관세 정책**이 상반기 최대 변수: 발표(▼)보다 **유예(▲) 쪽 당일 반응이 더 큼**(4/3 발표일 -0.76%, 보복관세 확전 4/7 -5.57% vs 유예 4/10 +6.60%). 관세 "서한"처럼 예상 범위 안의 발표는 오히려 불확실성 해소로 상승(7/8).
- **국내 정치 이벤트**는 뉴스량(N)은 최대지만 지수 영향(I)은 작음: 체포(1/15)·파면(4/4)은 당일 보합권이고 대선 다음날(6/4)만 +2.66%. 영향은 이후 **정책 기대(상법·밸류업)**를 통해 수주~수개월에 걸쳐 나타남 → 당일 가중치보다 **누적 창(event window)** 설계가 필요.
- **통화정책**: 한은 결정은 예상에 부합해 당일 영향이 작음(I=1~2). 예외는 서프라이즈 동결(1/16). 미 CPI·고용은 **예상 대비 편차**가 방향을 결정.
- **세제·증시제도**(공매도 재개 3/31 -3.00%, 세제개편 8/1 -3.88%)는 국내 고유 사건 중 영향력이 가장 큼 → 국가 간 비교(대만·일본 대비 초과하락)로 식별하기 좋은 사례.
- **실적 이벤트**는 "컨센서스 대비"와 주가 방향이 자주 엇갈림(삼성 4Q 쇼크에도 +3.43%, SK하이닉스 사상 최대에도 하락) → 기대 선반영 변수 필요.
